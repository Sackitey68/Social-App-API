# Social Blog API

A RESTful API for a social blogging platform built with Node.js, Express, and MongoDB.

## Features

- JWT authentication (1-hour token expiry)
- Posts with draft/published states
- Follow/unfollow users
- Like/unlike posts
- Pagination, filtering, search, and sorting
- Full test coverage with Jest + Supertest

## Getting Started

```bash
npm install
cp .env.example .env  
npm run dev

```bash
